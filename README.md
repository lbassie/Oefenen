# Oefenen

Leerproject om te oefenen met Claude Code en GitHub.

## Getallen-gokspel

De computer denkt aan een geheim getal tussen 1 en 100. Jij raadt, en krijgt
na elke gok de hint "Hoger!" of "Lager!" totdat je het juiste getal vindt.

### Spelen

Terminal-versie:

```bash
python gokspel.py
```

Browserversie (met confetti, ballonnen en geluid bij winst): open `index.html`
in je browser, geen installatie nodig.

### Tests

```bash
python -m unittest
```
